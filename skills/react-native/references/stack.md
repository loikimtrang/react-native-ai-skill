# Reference stack — versions & build config

The concrete stack this skill assumes. Versions are a baseline to match, not a mandate — follow
whatever the target project's `package.json` actually pins.

## Build tooling
| tool | version / detail |
|---|---|
| Language | TypeScript (strict mode) |
| Runtime | Expo SDK 54+ / React Native 0.81+ / React 19+ |
| Package manager | npm / pnpm / yarn per the project's lockfile |
| Native folders | `ios/`, `android/` — generated by `expo prebuild`, never hand-edited |
| Release builds | **EAS Build** (`eas.json` profiles: development / preview / production) |
| Bundle/package id | project-specific (check `app.json` / `app.config.ts`) |

## Run / build commands
```bash
# from repo root
npx expo start --dev-client       # Metro + dev client
npx expo run:ios                  # build + run on iOS simulator/device
npx expo run:android              # build + run on Android emulator/device
npx tsc --noEmit -p . --pretty    # definition-of-done type check
npx eslint . --fix                # lint

# release (local EAS build)
eas build --profile development --platform ios --local
eas build --profile production --platform android --local
```

## Env / config
Base URLs and keys are never hardcoded — read from `app/config/` (e.g. `API_URL`,
`MASTER_API_URL`), sourced from `app.config.ts` / EAS environment secrets per build profile.

## Localizations supported
`app/i18n/en.ts` + `app/i18n/vi.ts` at minimum — Vietnamese is this project's default locale. Add
more `*.ts` files as required and register them in `app/i18n/index.ts`.

## Notes
- **`observer()` everywhere a screen reads a ViewModel field** — skip it only when the screen has no
  ViewModel/observable state at all.
- **`makeObservable`, never `makeAutoObservable`, in a ViewModel** — `makeAutoObservable` throws on
  any class with a superclass, and every ViewModel extends `BaseViewModel`.
- **`actionBound`, not `action`/`action.bound`**, for a method passed directly as an event handler.
- **`repository.roomService` is lazy** — reading it is what opens the real `expo-sqlite` connection;
  a ViewModel test that never reads it stays safe under Jest without any mocking.
- **`reflect-metadata`** must be the very first import in `index.tsx` (and test setup) — Inversify's
  decorators depend on it being loaded first.
- Not every project needs every package here — treat this as the menu the codebase draws from.
